# World outline

`world-land.geojson` is Natural Earth's public-domain 1:110m land dataset, downloaded on 2026-10-14.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson

Terms: https://www.naturalearthdata.com/about/terms-of-use/

The map uses this local outline underneath its online tiles so shipment connections retain geographic context if the tile provider is unreachable. It is a low-resolution overview, not a navigation chart.
